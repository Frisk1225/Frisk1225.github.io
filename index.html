About me

I'm curious about the space between a chatbot that just talks and an agent that actually does work — reading documents, calling tools, checking results, and trying again when something fails.

Right now I'm studying Git, publishing with GitHub Pages, and building small prototypes that put an LLM inside a clear think → act → observe loop. I like simple, honest projects more than flashy demos.
